# Portfolio Update 2 - [View the Tidy Data Project](./TidyData_Project/)

This project applies tidy data principles to a dataset of 2008 Olympic
medalists using Python and pandas. The notebook transforms the original
dataset from wide to long format, separates combined variables, cleans
the data, and organizes different observational units into separate
tables. It then uses exploratory data analysis, visualizations, and pivot
tables to investigate medal distributions across sports, genders, and
medal types.
